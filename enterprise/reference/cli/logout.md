# `diffuse-coordinator logout`

End this session, here and on the coordinator.

## Synopsis

```
diffuse-coordinator logout [OPTIONS]
```

## Options

| flag | type | default | description |
|---|---|---|---|
| `--output <OUTPUT>` | one of `table`, `json` | `table` | Output format |

And the [connection options](index.md#connection-options).

## Examples

```bash
$ diffuse-coordinator logout
```

```
Signed out; the session is revoked on the coordinator.
```
