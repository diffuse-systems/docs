# `diffuse-coordinator account enable`

Switch it back on.

## Synopsis

```
diffuse-coordinator account enable <LOGIN> [OPTIONS]
```

## Arguments

| argument | type | required | description |
|---|---|---|---|
| `LOGIN` | text | yes | Which account |

## Options

Only the [connection options](index.md#connection-options).

## Examples

```bash
$ diffuse-coordinator account enable jonas.pfleger
```

```
jonas.pfleger is enabled again.
```
